# Generative AI Image Workflow & Illustrated Capstone E-book
# 生成式 AI 图像工作流与 Capstone 插图电子书

## Overview | 项目简介

This repository showcases part of my PMGT5850 Project Management Capstone Project at the University of Sydney.

本仓库展示的是我在悉尼大学 PMGT5850 项目管理 Capstone Project 中的一部分项目成果。

The project focuses on evaluating generative AI image tools and developing a repeatable workflow for producing consistent line-art illustrations for non-technical users.

该项目主要围绕生成式 AI 图像工具评估展开，并尝试建立一套可重复使用的工作流，让非技术用户也能够稳定生成风格一致的线稿插图。

我在团队中的主要职责是进度与风险管理。

我使用 Microsoft Project 搭建并持续维护项目进度计划，包括任务依赖关系、里程碑、关键路径分析、资源规划以及进度风险跟踪。

## Web Prototype | 网页原型

The prototype allows a user to:

该原型允许用户：

**Upload an image → Generate → Receive a line-art output**

**上传图片 → 点击生成 → 获得对应线稿**

The application integrates an image-generation API and hides the technical complexity behind a simple user interface.

该应用接入了图像生成 API，并通过简单的用户界面将后端技术流程封装起来，使用户不需要理解复杂的 Prompt、模型参数或 API 配置。
